# Lógica de Programação com Linguagem Lua

Este repositório reúne exercícios práticos para desenvolver o raciocínio lógico e a programação utilizando a linguagem Lua. O foco é oferecer exemplos simples e claros, ideais para iniciantes e para quem deseja reforçar os fundamentos da linguagem e da lógica de programação.
